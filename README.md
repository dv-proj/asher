# asher

[RUS](README.md) [ENG](README-EN.md)

Коллекция готовых shell-скриптов для быстрой настройки и развёртывания окружений на Ubuntu/Debian. Каждый скрипт лежит в своей папке вместе с документацией и запускается одной командой.

## Проекты

| Папка | Описание |
|---|---|
| [double-awg](double-awg/README.md) | **DoubleAWG** — каскадный VPN из двух VPS на [AmneziaWG](https://docs.amnezia.org/documentation/amnezia-wg/) (модуль ядра). Клиенты подключаются к первому серверу, трафик идёт через IPv6-канал на второй и выходит в интернет с него. Есть kill-switch и split-маршрутизация для российских IP. Скрипт запускается на вашей машине и настраивает оба сервера по SSH. |

### double-awg: быстрый запуск

```bash
curl -fsSL https://raw.githubusercontent.com/dv-proj/asher/main/double-awg/deploy-doubleawg.sh | bash
```

Требования, параметры и управление серверами описаны в [документации проекта](double-awg/README.md).

## Принципы

- Один скрипт — одна задача, без внешних зависимостей, кроме стандартных утилит.
- Перед изменениями скрипт показывает сводку и просит подтверждения.
- Секреты (ключи, пароли) сохраняются только локально, в папке с правами `700`.
